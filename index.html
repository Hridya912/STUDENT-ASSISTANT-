What is the difference between IaaS, PaaS, and SaaS in cloud computing?
G
Three core cloud service models:
• IaaS (Infrastructure as a Service): Provides raw computing, storage, and networking (e.g., AWS EC2). You manage the OS and apps.
• PaaS (Platform as a Service): Provides a managed development environment (e.g., Vercel, Heroku). You bring the code.
• SaaS (Software as a Service): Complete hosted software delivered over the web (e.g., Google Drive). Ready to use.

Project Introduction

Learning, made simpler.

Students can enter academic questions and receive structured explanations using the Grok AI API. The entire system is built for resilience, instant responsiveness, and zero maintenance overhead.

Structured Academic Explanations

Unlike generic web searches, questions submitted to the assistant receive targeted, step-by-step breakdowns designed specifically to reinforce academic comprehension.

Serverless Cloud Computing

The application is deployed on Vercel Functions. Dynamic requests invoke ephemeral serverless workers that run securely in the cloud without exposing secret credentials to the client.

Global CDN Distribution

Static frontend assets (HTML, CSS, and JavaScript) are delivered directly through Vercel's multi-region Content Delivery Network, guaranteeing ultra-low latency worldwide.

Workflow Process

How It Works

A four-step streamlined lifecycle that connects the student to cloud intelligence.

STEP 1

Ask a Question

The student enters a question through the chatbot interface in their web browser.

STEP 2

Cloud Processing

The question is sent securely to a Vercel serverless function (/api/chat) via HTTPS.

STEP 3

Grok AI Processing

The function communicates with the Grok API using the secret server key to generate an answer.

STEP 4

Receive Your Answer

The generated response is returned as clean JSON and formatted in the chatbot.

Important Architectural Clarification

The Grok AI model does not run inside the Vercel CDN. Vercel's global CDN delivers static frontend assets (HTML, stylesheets, scripts) with edge caching. The dynamic /api/chat endpoint triggers a serverless Vercel Function that securely contacts xAI's remote inference endpoints.

Vercel CDN Edge

Delivers immutable static assets from globally distributed points of presence, caching pages close to visitors for near-instant first paint times.

Serverless Function

Validates incoming user questions, sanitizes parameters, verifies character limits, and securely injects the private XAI_API_KEY on the server side.

xAI Grok Responses API

Processes the prompt using fine-tuned reasoning models and produces structured explanations formatted with markdown, headings, and clean bullet points.
